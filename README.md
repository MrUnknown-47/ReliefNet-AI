# ReliefNet AI

A disaster response platform built with Flutter, FastAPI, and Firebase Firestore.

## Project Structure

- `frontend/mobile_app`: Flutter application.
- `backend/`: FastAPI Python server and AI services.
- `docs/`: Project documentation.
- `scripts/`: Utility scripts for automation.

## Running the Backend

Local development:
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Using Docker:
